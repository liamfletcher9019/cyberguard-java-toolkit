# CyberGuard Java Toolkit

CyberGuard is a Java-based cybersecurity toolkit designed to assess password strength and analyze authentication logs. The password strength assessment evaluates password length, character variety, common passwords, and predictable patterns using wordlists to identify potential weaknesses and provide security recommendations.

## Current Features
- Password strength assessment
- Password input validation
- Common-password and common-word datasets
- Sample authentication log datasets for testing and development

## In Development
- Security log generator with a consistent log format
- Detection of brute-force attempts and username enumeration
- Identification of suspicious authentication activity
- Security reports and basic threat assessment

## Technologies
- Java
- File handling and text processing
- Git and GitHub

## Project Goal
Build a practical cybersecurity toolkit that applies Java programming concepts to password security, authentication log analysis, and defensive security monitoring.
